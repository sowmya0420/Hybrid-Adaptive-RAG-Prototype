# Hybrid Adaptive RAG Prototype

## Overview
This project implements a prototype for Hybrid Adaptive Retrieval-Augmented Generation (RAG), combining retrieval techniques to improve the relevance of retrieved information.

## Contents
- `Hybrid_Adaptive_RAG_Prototype.ipynb` — Organized Jupyter notebook containing the prototype implementation and experiments.

## Technologies
- Python
- Dense retrieval and embeddings
- BM25 sparse retrieval
- Hybrid retrieval
- Retrieval evaluation metrics

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Run the environment setup cell to install the required dependencies.
3. Execute the notebook cells in order.

## Project Status
Prototype and experimental implementation.
